# Crowned App Implementation

This directory is reserved for the executable Crowned application once the Base44 project is linked/exported into the dedicated product repository.

Do not hand-create a fake Base44 configuration here before the real Base44 project exists. When the app is connected, preserve generated project configuration and reconcile it against the canonical product/design/implementation contracts in the parent repository.

The executable app must not become the source of product truth by accident. Product scope lives in `/product`, approved visual behavior in `/design`, and engineering decisions in `/implementation`.
